Next steps to launch

Follow these steps on your phone.

  1. Create a new public repository on GitHub named nav-computer-education (you can choose another name).
  2. Add a file named index.html and paste the contents of this file.
  3. Commit the file, then open the repository's Settings → Pages and select the main branch and /(root) folder.
  4. After GitHub Pages publishes it, open the website URL shown on the Pages settings screen.
  5. Before real student accounts or certificates: create a Supabase project, configure Auth and database tables, enable Row Level Security, and test access rules. Never put a service-role/secret key in website code.
